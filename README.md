# 學測英文智慧學習工作室 v6

可單檔離線使用的英文句型練習、主動回想與 A4 組卷工具。開啟 [index.html](./index.html) 即可使用，不需帳號、API 金鑰、套件安裝或雲端服務。學習資料保存在目前瀏覽器，換裝置、網址或清除瀏覽資料前請先備份。

## v6 升級

- **58,465 句**：保留原有 23,353 句及其 ID，新增 35,112 句。其中 **58,368 句為模板變體**，**97 句為考點原創**，不是五萬多句逐句人工審校的獨立教材。
- 新增 10 個主題：科學探究、數位安全、生涯探索、公民參與、食物永續、文化保存、團隊合作、情緒調適、無障礙設計、防災準備。共 24 個模板主題、38 種模板。
- 對照本次提供的 **111、112、113、115 年試卷第 1–10 題**，新增 40 句雙語原創延伸例句及用法提醒。114 年與其餘舊例句沿用 v5，不宣稱本次重新核對。
- **適性組卷**：結合到期時間、自評難度、新句、主題與句型多樣性，接近目標抄寫詞數，並依實際版面調整頁數。只挑新句、只挑已練習及只挑到期複習為嚴格篩選；無符合內容時會說明原因。
- **主動回想**：先看中文、回想英文，再顯示參考句並自評。不熟：10 分鐘後重練；吃力：1 天後；熟悉：3 天起，每次約乘 2.2，上限 180 天。這是本機規則式排程，不是 AI 自動批改或能力測驗。
- 收藏、學習狀態與來源篩選；多關鍵字、`"完整片語"` 和 `-排除詞` 搜尋。例如 `"tight schedule" doctor -mayor`。
- 完整備份可還原自編句、選句、隱藏、收藏、設定與學習紀錄。支援舊版 v3 備份格式；匯入完整備份會先確認覆蓋，例句 JSON 陣列則合併去重（自編上限 3,000 句）。
- 列印不再計入練習次數；舊紀錄保留，但不當成新的自評結果。長句格線可跨頁接續；修正版面使用率。

## 使用流程

1. 在「句庫搜尋」選年份、來源、主題、句型或學習狀態。
2. 設定目標詞數、抄寫次數與頁數，再按「智慧組卷」，或直接勾選例句。
3. 按「開始練習已選例句」進行回想與自評；完成的句子立即存檔，提前結束不會標記未完成句子。
4. 需要紙本時列印／存 PDF。自行加入的選句可以超過頁數上限，預覽會顯示提示；單句本身超過上限時請減少抄寫次數。
5. 定期使用「備份」。收藏和複習時間不會自動跨裝置同步；舊版本程式不支援 v6 的新功能資料。

模板練習用於反覆練習句型，不能取代篇章閱讀及作文修訂。不同模板組合的情境自然度可能不同；考點延伸句是原創練習，不是官方考題或官方解答。自評時可接受其他正確的英文表達。

## 開發

使用 Node.js 18 以上（本次驗證為 24）和 Python 3。無 npm 相依套件。

```sh
node scripts/build.mjs        # 將原始碼內嵌成可獨立使用的 index.html
node scripts/build.mjs --check
node verify_v5.cjs            # 同時保護 v5 資料與 v6 句庫完整性
node --test tests/core.test.cjs
python3 -m http.server 8000 --bind 127.0.0.1
```

- `src/index.template.html`：介面與列印樣式。
- `src/core.js`：可獨立測試的搜尋、複習排程、組卷引擎。
- `src/app.js`：舊句庫生成、資料保存、介面、組卷與分頁。
- `src/expansion.js`：新增主題、句型、40 句考點延伸與解析。
- `exam_111_115.js`：保留的 v5 考點來源。
- `index.html`：自動建置的單檔產物；請修改 `src/` 後重新建置。

瀏覽器回歸測試需要 Python Playwright 與 Chromium，可用 `CHROMIUM_PATH` 指定執行檔：

```sh
python3 tests/browser_smoke.py
```

測試會自行啟動臨時本機伺服器，使用獨立瀏覽器環境，不會修改使用者紀錄。驗證搜尋、收藏、自評、重載保存、備份往返、舊版還原、錯誤匯入、A4 PDF、長句跨頁與手機寬度；亦檢查無外部請求及載入後斷網操作。

本次雲端 Chromium 政策禁止 `file://` 導航，直接雙擊檔案的流程未能在此環境驗證；已驗證完整內嵌產物、HTTP 載入及斷網後操作。環境原有的 Python Playwright 與 Chromium 可直接用於測試。
