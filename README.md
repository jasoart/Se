# 學測英文智能罰寫組卷系統 v5

111～115 學測考點導向句型擴充版。原有的 A4 即時分頁、英文四線格、智能組卷、練習紀錄、匯入／備份均保留。

## 使用

**[開啟新版 index.html](./index.html)**。下載 `index.html` 到電腦後用瀏覽器開啟即可離線使用；所有句庫已內嵌，不需要額外下載 JS。

首頁「句庫搜尋」可選擇「**歷屆年份**」（111～115），只瀏覽附有題號的考點練習句。也可以搜尋詞組，如 `due to`、`pose as`、`had yet to`、`give rise to`。只選「句型」可查看新增的進階句型練習。

## 本次更新

- 原有 **12,544** 句生成例句保留。
- 新增 **12 種**文法模板，覆蓋讓步、強調句、對比、條件、名詞子句、段落承接，生成 **10,752** 句。
- 依 111～115 學測五份試卷，挑選 **57 個有年份／題號的具體考點**，逐一編寫 **57 句新的雙語例句**（111／112／113／114 各 11；115 為 13）。
- **總計 23,353 句**，以英文全文比對，沒有完全重複的句子。
- 新增年份篩選和題號顯示；沿用舊版瀏覽器紀錄 key `gsat-writing-v3`，以降低升級後遺失學習紀錄的風險。

## 學測考試說明依據

對照使用者提供的 111～115 學測英文試卷與《115 學年度起適用學測英文考科考試說明》。115 起「篇章結構」為 **四空、五選項**；單句練習僅涵蓋其中部分語法和銜接能力，不等於完整篇章作答。

## 著作權與準確性

上述新寫的練習句**不是大考中心正式考題的逐字重製**。「歷屆年份／題號」只是用來標記激發該句型、詞組的考點，並非宣稱該句曾出現在題本。大量模板產生的句子適合練習用，不能取代完整篇章閱讀、文章理解與作文修訂。
